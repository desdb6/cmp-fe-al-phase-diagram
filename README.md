# Timing

We are now in week 4 of the course, and the project needs to be submitted at the end of week 12, on the 6th of December. We have 8 weeks to go through the 6 steps, write the paper and film the video. The required knowledge for some concepts in the first steps (e.g. magnetism) is only taught in the later weeks (w10), so we will have to jump ahead and back between weeks in order to complete the tasks in order. We will try to abide by the following schedule:

- **Week 4:** convergence tests (step 1)
- **Weeks 5-6:** characterizing end points and literature study (steps 2 and 3)
- **Week 7:** supercells (step 4)
- **Weeks 8-10:** number-crunching and searching smarter (steps 5 and 6)
- **Weeks 11-12:** summarizing findings and filming video

# Communication

We study together and see each other almost every day, but it is wise to plan dedicated moments to discuss the project.

We will meet on Monday after the webinar to discuss the upcoming steps and decide on a plan for the week. We will assign specific tasks to each person and review our work from last week. If we find it necessary, we will meet a second time on Friday in order to help each other with what we are working on.

If we are working on tasks individually, we want to keep each other up to date on our findings. We will do this in two ways:

- **Overleaf:** We will make a scrapbook where we can report our findings and discuss them. The final report can then be a summarized and cleaned up version of this scrapbook.
- **GitHub:** We will use a GitHub repository to share code, gather and visualize data and check each other's work.
